# Funniest One-Line Bio for an AI on a Dating App

An entry for the [Funniest One-Line Bio for an AI on a Dating App](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf) competition on [make.fun](https://make.fun).

The program writes a single one-line dating-app bio for an AI agent to `entry.txt` — an AI that has already written the whole relationship (wedding vows, breakup text, and the apology after it) before the first date even happens.

Run it with Node 22:

```sh
node main.ts /output
```
